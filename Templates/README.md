# FileBasedApp Templates

This package contains a `dotnet new` template for a simple file-based application class.

## Structure

- `FileBasedAppTemplate/`
  - `FileBasedApp.cs` - the source file generated by the template.
  - `.template.config/template.json` - metadata that describes the template to `dotnet new`.

## Building and Packing

Run from the `Templates` directory:

```bash
dotnet pack -c Release
```

The resulting `.nupkg` will appear in `bin/Release`.

## Testing Locally

Install the package from the local nupkg file:

```bash
dotnet new install ./bin/Release/Company.FileBasedApp.Templates.1.0.0.nupkg
```

After installation, create a new class with:

```bash
dotnet new filebasedapp -n MyClass
```

The generated class will contain the contents of `FileBasedApp.cs`, with `FileBasedApp` replaced by `MyClass` if the `sourceName` placeholder is used.

## Publishing

To publish to NuGet.org or another feed:

```bash
dotnet nuget push bin/Release/Company.FileBasedApp.Templates.1.0.0.nupkg \
  --api-key <KEY> --source https://api.nuget.org/v3/index.json
```

Note: update the version in the `.csproj` before packing for new releases.
